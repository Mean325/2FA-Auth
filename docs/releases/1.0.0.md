# 钥记 1.0.0

首个 macOS 版本，支持 macOS 14 及以上，安装包同时支持 Apple Silicon 和 Intel。

- 菜单栏查看、搜索和复制 TOTP、HOTP、Steam 验证码。
- 手动添加、二维码扫描和备份导入，支持账号管理与拖拽排序。
- iCloud 同步、Touch ID 解锁、浅色与深色外观、中英文切换。
- 应用内检查更新，自动下载、验证签名并安装新版。

首次安装请下载 DMG，将「钥记」拖到「应用程序」。后续可在「通用 → 关于」或状态栏右键菜单中检查更新。

---

First macOS release. Requires macOS 14 or later; supports Apple Silicon and Intel.

- View, search and copy TOTP, HOTP and Steam codes from the menu bar.
- Add accounts manually, scan QR codes, import backups and reorder accounts.
- iCloud sync, Touch ID, light/dark appearance and Chinese/English support.
- Check for updates in the app; automatically download, verify and install new versions.

For the first installation, download the DMG and drag the app to Applications. Check for future updates under General → About or from the menu bar's context menu.
