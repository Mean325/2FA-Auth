# 钥记 1.0.1

- 新增「SMS Code管理」和「Email Code管理」设置入口，目前显示「功能开发中」。
- 新增「拓展」设置页，支持切换开发、测试、沙箱和生产环境，并记住当前选择。
- 展示 Pyvio、Actyve、Cardbin、FreeUTX、RUB 和 GetShift 项目及品牌图标；点击信息按钮可查看项目、当前环境和开发状态。
- 拓展列表和信息弹窗参考 macOS 系统设置样式，顶部标题与其他设置页保持一致。
- 调整设置侧栏图标，新增界面文案兼容简体中文和英文。

本版本尚未接入短信或邮箱验证码服务。

首次安装请下载 DMG，将「钥记」拖到「应用程序」。已有用户可在「通用 → 关于」或状态栏右键菜单中检查更新。

iCloud 同步暂未开放。此版本使用 ad-hoc 签名，未经 Apple 公证；更新包经过 Sparkle Ed25519 签名校验。

---

- Added SMS Code Management and Email Code Management settings pages, currently displaying “Feature in development.”
- Added Extensions settings with Development, Test, Sandbox and Production environment selection, saved locally.
- Added project lists and brand icons for Pyvio, Actyve, Cardbin, FreeUTX, RUB and GetShift. Information buttons show the project, current environment and development status.
- Matched the extensions list and information sheets to macOS System Settings, while keeping the page header consistent with other settings pages.
- Updated sidebar icons and added Simplified Chinese and English translations for the new interface.

SMS and email verification code services are not connected in this release.

For the first installation, download the DMG and drag the app to Applications. Existing users can check for updates under General → About or from the menu bar's context menu.

iCloud sync remains unavailable. This release is ad-hoc signed and has not been notarized by Apple. Update archives are verified with Sparkle Ed25519 signatures.
